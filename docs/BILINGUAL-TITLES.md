# 双语标题（2026-10-31）

网站与 RSS Reader 插件统一为中文标题在上、英文原题在下。未翻译时立即显示原题，译文不可用或与原题重复时不增加副标题。

标题翻译从 SQLite 分页扫描元数据，跳过有效缓存、已删除文章、停用来源和无需翻译的标题，不再只看最新 1000 篇。自动改写队列及定时补偿都会独立补标题；正文 autoRewrite=false 不禁止标题翻译。每轮默认最多 80 篇，仍使用已有 AI 预算。

历史补齐只处理标题，不翻译正文或触发改写：

```
node scripts/backfill-titles.js --limit=1000
node scripts/backfill-titles.js --limit=1000 --execute
```

先读 dry-run 的来源及数量，再按需要指定 1–10000 的上限。每篇最多沿用批量翻译的两次尝试，失败/日预算耗尽停止并报告。版本标识和实际生产回填结果记录在发布证据中。

用户刷新列表会异步 POST /api/title-translations，最多提交当前 40 篇文章 ID。服务端只接受已存在且启用来源的文章，任务合并为单队列，每批 20 篇，排队上限 200，同标题十分钟内不重复申请，使用 deepseek-flash 和原有预算护栏。接口立即返回；客户端最多每两秒读取一次结果，最多两分钟，译名返回后自动替换列表标题。GET 只读，生成请求不转发只读备用站。未配置 AI、旧服务器、失败或额度耗尽时仍可阅读英文原题。个人库本地内容不上传到服务器请求翻译。
