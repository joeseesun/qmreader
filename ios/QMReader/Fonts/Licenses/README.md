# QMReader 内置字体与许可证

本目录保留随 App 分发字体的上游许可证。五款字体均选自上游明确采用 SIL Open Font License 1.1 的项目，只打包阅读所需的 Regular 文件；系统苹方不随 App 分发。

| App 内名称 | 随包文件 | 上游版本/快照 | 来源 | 许可证 |
| --- | --- | --- | --- | --- |
| 霞鹜文楷 | `LXGWWenKaiGBLite-Regular.ttf` | v1.522 | https://github.com/lxgw/LxgwWenKai | SIL OFL 1.1 |
| 霞鹜文楷 TC | `LXGWWenKaiTC-Regular.ttf` | v1.522 | https://github.com/lxgw/LxgwWenkaiTC | SIL OFL 1.1 |
| 朱雀仿宋 | `LXGWZhuqueFangsong-Regular.ttf` | 2026-08-23 上游/CTAN 快照 | https://github.com/TrionesType/zhuque | SIL OFL 1.1 |
| 思源宋体 CN | `SourceHanSerifCN-Regular.otf` | 2.003R | https://github.com/adobe-fonts/source-han-serif | SIL OFL 1.1 |
| 文津宋体 | `WenJinMinchoP0-Regular.otf` | v2.020 | https://github.com/takushun-wu/WenJinMincho | SIL OFL 1.1 |

许可证正文分别位于同目录的 `*-OFL.*` 文件。更新字体时必须重新核对上游许可证、文件的 PostScript Name，并在真机中确认菜单示例和文章正文均实际切换。
