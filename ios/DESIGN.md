# QMReader iOS Design System

## 1. 视觉主题与氛围

Reeder 4 式原生阅读器：暖白纸面、低饱和中性色、细分隔线和克制的系统控件。内容是唯一焦点，界面不模拟浏览器，也不堆卡片。

## 2. 色板与角色

- 阅读背景支持自动、暖纸、素白、深夜四种外观；自动随系统在暖纸与深夜间切换。
- Paper：暖纸 `#FAF8F4`、素白 `#FCFCFB`、深夜 `#161513`。
- Ink：暖纸 `#1E1C19`、素白 `#1C1B19`、深夜 `#E9E6E0`。
- Secondary：`#8C877D`；深夜 `#A39D93`，用于原标题与作者信息。
- Meta：`#716B61`；深夜 `#B5AEA4`，用于日期、图注与小字号提示，保证比 Secondary 更易读。
- Quote Fill：`#F2EEE5`；深夜 `#201D1A`。引用使用完整浅色面，不使用左侧竖线。
- Code Fill：`#EDE9DF`；深夜 `#211E1B`，外加 Ink 12% 的 0.5pt 描边。
- Placeholder：`#EDEAE3`；深夜 `#242220`，只用于骨架与图片占位，不兼任内容块背景。
- Accent：暖赭 `#A65A2E`；深夜 `#D08A5B`，只用于链接、收藏和选中态。

## 3. 排版规则

- 使用 iOS 内置字体，不下载或打包大体积中文字体。正文可切换苹方、宋体、楷体；字体不可用时回落苹方。所有字体通过 `relativeTo` 支持 Dynamic Type。
- 中文正文默认 17pt，可选 15/17/19/21pt；行距有紧凑/舒适/宽松三档。SwiftUI `lineSpacing` 是自然行高之外的附加值，三档分别按字号的 0.42/0.47/0.56 计算并随 Dynamic Type 缩放。
- 文章标题 26pt/600，并随 Dynamic Type 缩放。文内 H1/H2/H3 分别为正文 ×1.32/×1.16/×1.06；H3 使用 600 字重，与整段粗体正文保持可扫读差异。
- H1/H2/H3 段前距分别 34/28/22pt；标题后的内容距 10pt。层级靠“远离上文、贴近下文”的不对称节奏建立，不加装饰线或序号。
- 正文段距 16pt；连续列表项 8pt；正文进入列表 12pt；图片、引用、代码前后 20pt。段首不缩进。
- 引用保持正文字号与行距，使用 Quote Fill；代码块使用正文减 2.5pt 的等宽字体、Code Fill 和细描边，可横向滚动。
- 图片保持原比例、限制在正文栏内，单图高度上限 520pt；图注 12.5pt、8pt 贴近图片。
- 来源、日期 12pt/500；摘要 15pt/400。
- 中文字重只用 400/500/600，无斜体、无负字距。

## 4. 组件样式

- 列表使用留白与 0.5pt 分隔线，不使用卡片或阴影。
- 缩略图 74×74pt、10pt 圆角；无图片时不显示占位块。
- 所有图标按钮触控区至少 44×44pt。
- 阅读模式通过底栏“译”菜单切换，不放常驻原文/翻译 Tab。
- `Aa` 打开原生阅读外观面板，在一个紧凑 sheet 内调整字号、字体、行距和背景；选择即时生效并持久化。

## 5. 布局原则

- 单一 `NavigationStack`：文章列表 → 阅读页。
- 屏幕水平边距 20pt，正文最大宽度 640pt。
- 阅读页顺序固定：日期 → 标题 → 作者/来源 → 图片 → 正文。
- 首屏先展示缓存；网络刷新不清空已有内容。

## 6. 深度层级

- 页面与列表为 Level 0，纯纸面。
- 底部系统工具栏为 Level 1，使用系统材质或纸面色，不叠加阴影。
- 错误与刷新反馈使用短暂轻提示，不常驻占位。

### 刷新反馈契约

- 下拉刷新保留当前文章，不清空列表，也不回退到整屏 loading。
- 请求阶段使用系统刷新控件；服务端仍在处理时结束手势并显示一次「正在准备新内容，好了会自动出现」。
- 后台每 8 秒轻量检查一次，发现新内容提示「有 N 篇新文章」。无变化提示「已经是最新的」。
- 文案只描述用户结果，不出现「源站、队列、改写管线、已提交」等内部实现词。
- 离线提示「现在没有网络，先看已保存的内容」；错误提示「这次没刷新成功，稍后再试」。

### 链接加入契约

- 正文链接必须保留可点语义与 Accent 颜色。
- 长按含链接的正文可选择「加入乔木阅读」或「复制链接」；加入后后台抓取并生成乔木改写。
- 重复链接直接提示已加入；离线时本地排队，联网后自动重试。

## 7. Do / Don't

- Do：秒开缓存、后台刷新、原生返回手势、系统分享、离线可读。
- Do：图片作为阅读节奏，失败时不破坏文字布局。
- Don't：WKWebView、紫蓝渐变、左侧装饰竖线、浏览器式工具栏、卡片泛滥。
- Don't：等待翻译接口后才显示原文。

## 8. 响应式

- iPhone SE 到 Pro Max 保持单栏；标题、正文与附加行距一起支持 Dynamic Type，辅助功能大字号下外观面板可滚动。
- iPad 仍为居中单栏阅读，正文宽度不超过 640pt。
- 横屏和大字号允许自然滚动，不裁切错误状态。

## 9. Motion 哲学

- 优先使用系统 `NavigationStack`、刷新和菜单反馈。
- 高频阅读操作不加装饰动画；状态变化保持短、可中断。
- Reduce Motion 下不依赖位移动画表达状态。

## 参考 DNA

- Reeder 4：暖纸色、来源小字/标题/摘要/缩略图的列表节奏，阅读页大标题与轻底栏。
- Apple：17pt 正文字阶、48–52pt 紧凑导航、44pt 触控热区、系统分享与返回手势。
